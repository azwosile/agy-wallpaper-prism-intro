## 四、分区、投稿设置与发布时段建议

### 1. 分区选择
- **首选分区：`科技 → 软件应用`**  
  原因：工具/插件展示、IDE 美化、桌搭效率类视频在「软件应用」分区的新手转化率与完播率最高，容易触发“实用软件/宝藏插件”推荐池，且对《崩坏3》壁纸 + 曼波解说的轻快画风包容度极强。
- **备选分区：`科技 → 计算机技术`**  
  原因：如果你更侧重吸引重度开发者去 GitHub 点 Star（如关注 `PKGV/LZ4`、`MP4 Faststart`、`WCAG` 架构细节），该分区极客浓度更高，但首页泛流量略低于「软件应用」。

### 2. 投稿参数与互动设置
- **类型**：`自制`（勾选「未经作者授权禁止转载」或按个人习惯开启二创）。
- **画质确认**：成片已按 `1920×1080 @ 60fps`、`H.264 High@4.2`、`CRF 17`、`AAC 192kbps -14 LUFS` 压制，上传后可无损激活 B 站 **1080P60 高帧率** 档位。
- **动态同步文案（投稿页「粉丝动态」栏）**：
  > 曼波~ 给 Google Antigravity 写了一套开源浮岛毛玻璃 + 动态壁纸插件 `Wallpaper Prism v1.1.0`！直接读取 Steam 创意工坊壁纸、不改 `app.asar`、0 Token 消耗，还做了 `Ctrl+Alt+W` 快捷浮窗和普通快捷方式自动加载~ 仓库在简介和置顶评论，欢迎来玩！
- **黄金发布时间窗口**：
  - 工作日：**18:00 – 20:30**（开发者下班通勤 + 晚间刷 B 站高峰）
  - 周末/节假日：**11:30 – 13:00** 或 **19:00 – 21:00**
